# 路线图 Roadmap

## v0.1（当前）
- [x] 离线浮雕模式（零依赖、可跑）
- [x] AI 模式适配层（Hunyuan3D / TripoSR 接口）
- [x] 打印级后处理：水密 / 减面 / 摆正 / 毫米缩放
- [x] OBJ / PLY(带色) / 3MF 导出
- [x] 中文 Web UI

## v0.2（易用性）✅ 已完成
- [x] 异步任务队列（AI 模式耗时长，前端显示进度）—— `POST /api/generate_async` + `GET /api/tasks/{id}`，前端轮询分阶段进度条
- [x] 在线公共 Demo（无需本地部署即可体验）—— **https://snapprint-3d.surge.sh**（纯浏览器版：浮雕 / 拉伸 / 真实3D / 导入 / 3DGS 五模式 + 33 款模型库）
- [x] 一键导出「切片就绪」预设（按常见打印机推荐参数）—— 内置拓竹 A1/A1 mini/P1S、创想 Ender-3 V3/K1C、Prusa MK4S、Elegoo、Anycubic 等 9 款机型 × PLA/PETG/TPU 材料；基于模型几何自动推荐层高/填充/支撑/Brim，超床警告，导出 PrusaSlicer/OrcaSlicer 可导入的 `.ini` 与中文参数卡

## v0.3（生态）✅ 已完成
- [x] Blender 插件（在 Blender 内直接调用）—— `blender/SnapPrintBlender/`：面板支持「从图片生成浮雕」（调本地后端 `/api/generate_async` 轮询并导入 OBJ）、「分析可打印性/支撑」（调 `/api/analyze`）、一键打开在线 Demo / 本地后端
- [x] ComfyUI 节点（融入 AI 工作流）—— `comfyui/SnapPrintNode/`：注册 `SnapPrintGenerate`（图片→3D 网格文件路径）、`SnapPrintAnalyze`（可打印性建议 JSON），直接连本地后端
- [x] 自动支撑生成建议（面向 FDM 打印）—— `app/advisor.py` 几何分析：悬垂角判定、支撑密度/类型(tree/normal)/阈值/摆放建议/Brim/层高/填充，并提供 `POST /api/analyze`；Web 切片面板与 Blender 插件共用口径

## v0.4（社区）✅ 已完成
- [x] 模型动物园（垂类权重）—— `app/config.py` 的 `MODEL_ZOO` 注册表（Hunyuan3D-2 / TripoSR + 手办 / 珠宝 / 电商），`backends.py` 按权重目录加载；`POST /api/models` 列出并探测本地权重可用性；Web「AI 模型」下拉 + Blender/ComfyUI 可选
- [x] 批量处理与 API Key 限流 —— `POST /api/batch` 多图批量异步生成；可选 `SNAPRINT_API_KEY`（X-API-Key 校验）+ `SNAPRINT_RATE_LIMIT`（每客户端每分钟 N 次令牌桶限流），供小团队内网部署
- [x] 多语言文档 —— `README.en.md` 英文版；Web UI 右上角中英一键切换（`data-i18n` 轻量 i18n，初始按浏览器语言 / localStorage）

## v0.5（生成模式对齐 modly）✅ 已完成
- [x] 多引擎图生 3D —— 模型动物园从 4 款扩到 10 款，对齐 [modly](https://github.com/lightningpixel/modly) 的图生3D 阵容：`Hunyuan3D-2` / `Hunyuan3D 2 Mini` / `Mini Turbo` / `Mini Fast` / `TripoSG` / `SF3D` / `Trellis2 GGUF` + 手办 / 珠宝 / 电商垂类；`backends.py` 按条目 `backend` 路由（hunyuan3d / triposr / sf3d / trellis），`MODEL_ZOO` 新增 `speed`/`texture`/`params` 富字段与 `SPEED_TAGS` 档位标签
- [x] 生成参数（remesh / 贴图）—— 对齐 modly 的 `POST /from-image` 参数面：`remesh`(none/triangle/quad)、`enable_texture` + `texture_resolution`；`backends.py` 新增 `_apply_remesh`（quad 走 pymeshlab，缺失安全回退三角并附 note）与 `_apply_texture`（`False` 时烘焙为顶点色利于单色打印）；`pipeline.run()` 透传
- [x] API 接入 —— `/api/generate`、`/api/generate_async`、`/api/batch` 各新增 `remesh` / `enable_texture` / `texture_resolution` / `params` 表单字段；`_parse_params()` 容错解析
- [x] 统一后端托管前端 —— 后端 `app.mount("/", StaticFiles(web/, html=True))` 直接托管 `web/`（删除冗余的 `frontend/`）；`Dockerfile` 改 `COPY web ./web`；跨域（surge 静态站 → 本地后端）通过 `<meta name="api-base">` + CORS 中间件（`allow_origins=["*"]`）自动适配；前端 `generateAI()` 走异步任务队列并轮询渲染下载
- [x] 测试 —— `tests/test_v05.py` 覆盖新引擎路由、remesh/texture helper、API 参数；CI pytest 全绿

> 差异化主线不变：**把「照片 → 可打印成品」这一公里走完**，而不是再造一个通用图生 3D 引擎。新引擎（SF3D / Trellis2）以「清晰报错的适配层」落地，避免引入未验证的重依赖；真正可用需用户自备 GPU + 权重。
