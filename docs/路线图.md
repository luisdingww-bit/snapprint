# 路线图 Roadmap

## v0.1（当前）
- [x] 离线浮雕模式（零依赖、可跑）
- [x] AI 模式适配层（Hunyuan3D / TripoSR 接口）
- [x] 打印级后处理：水密 / 减面 / 摆正 / 毫米缩放
- [x] OBJ / PLY(带色) / 3MF 导出
- [x] 中文 Web UI

## v0.2（易用性）
- [ ] 异步任务队列（AI 模式耗时长，前端显示进度）
- [ ] 在线公共 Demo（无需本地部署即可体验）
- [ ] 一键导出「切片就绪」预设（按常见打印机推荐参数）

## v0.3（生态）
- [ ] Blender 插件（在 Blender 内直接调用）
- [ ] ComfyUI 节点（融入 AI 工作流）
- [ ] 自动支撑生成建议（面向 FDM 打印）

## v0.4（社区）
- [ ] 模型动物园（社区微调的垂类权重：手办 / 珠宝 / 电商）
- [ ] 批量处理与 API Key 限流（供小团队内网部署）
- [ ] 多语言文档（中英双语）

> 差异化主线不变：**把「照片 → 可打印成品」这一公里走完**，而不是再造一个通用图生 3D 引擎。
