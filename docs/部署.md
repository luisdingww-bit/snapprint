# 部署与接入 AI 模式

## 一、最小可用（离线浮雕模式）

不需要显卡、不需要任何模型权重。按 README 的「快速开始」启动即可。
该模式把照片亮度转成带颜色的浮雕刻印，满足「开箱即跑」。

## 二、接入 Hunyuan3D（更立体的模型）

1. 从官方仓库获取 Hunyuan3D 权重与推理代码。
2. 放到 `models/` 目录，结构示例：
   ```
   models/
   └── hunyuan3d_pipeline.py   # 需导出 build_pipeline(model_dir) -> 对象
                              # 对象须实现 image_to_mesh(image: PIL.Image) -> trimesh.Trimesh
   ```
3. 在 Web UI 选择「AI 模式（Hunyuan3D）」或调用：
   ```python
   from app.pipeline import run
   run(image_bytes, mode="hunyuan3d", out_dir="outputs/demo")
   ```

## 三、接入 TripoSR（轻量快速）

同样在 `models/` 放置 `tsr_pipeline.py`，导出 `build_pipeline(model_dir)`，
实现 `image_to_mesh`。Web UI 选择「AI 模式（TripoSR）」。

> 统一接口：`image_to_mesh(image: PIL.Image) -> trimesh.Trimesh`
> SnapPrint 只定义契约，不捆绑任何后端，方便自行替换。

## 四、Docker 部署到服务器

```bash
docker compose up --build -d
# 反向代理（nginx/caddy）把 8000 端口暴露出去即可
```

生成文件在宿主机 `./outputs`，权重在 `./models`，均已挂载。
