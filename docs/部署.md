# 部署与接入 AI 模式

## 一、最小可用（离线浮雕模式）

不需要显卡、不需要任何模型权重。按 README 的「快速开始」启动即可。
该模式把照片亮度转成带颜色的浮雕刻印，满足「开箱即跑」。

## 二、接入 Hunyuan3D-2（质量最高的图生 3D）

> 前置：**NVIDIA GPU + CUDA**。CPU 基本跑不动。

1. 安装带 CUDA 的 PyTorch（按你的驱动版本选 cu 链接）：
   ```bash
   pip install torch --index-url https://download.pytorch.org/whl/cu121
   ```
2. 安装 Hunyuan3D 推理包：
   ```bash
   pip install hy3dgen
   ```
3. 在 Web UI 选择「AI 模式（Hunyuan3D）」或调用：
   ```python
   from app.pipeline import run
   run(image_bytes, mode="hunyuan3d", out_dir="outputs/demo")
   ```
4. 权重默认自动从 HuggingFace (`tencent/Hunyuan3D-2`) 拉取；
   如需离线，把模型放到 `models/Hunyuan3D-2`，程序会优先用本地权重。

## 三、接入 TripoSR（轻量快速）

> 前置：**NVIDIA GPU + CUDA**。

1. 把 TripoSR 仓库克隆到 `models/`：
   ```bash
   git clone https://github.com/stabilityai/TripoSR models/TripoSR
   pip install -r models/TripoSR/requirements.txt
   ```
2. 在 Web UI 选择「AI 模式（TripoSR）」或调用：
   ```python
   from app.pipeline import run
   run(image_bytes, mode="triposr", out_dir="outputs/demo")
   ```
3. 权重默认自动拉取 `stabilityai/TripoSR`；也可离线放置到 `models/TripoSR`。

## 四、统一接口契约（想接别的模型就看这里）

任意后端只需实现：
```python
def image_to_mesh(self, image: PIL.Image) -> trimesh.Trimesh:
    ...
```
SnapPrint 的 `backends.HunyuanBackend` / `TripoSRBackend` 已按此契约
对接真实开源库，并通过 `_to_trimesh()` 把不同返回类型统一成 trimesh。
要加新后端：在 `app/backends.py` 继承 `Backend`，并在 `get_backend()` 注册即可。

## 五、命令行批量生成（适合 GPU 服务器）

```bash
python scripts/generate_cli.py photo.jpg --mode hunyuan3d --out outputs/cli --device cuda --steps 50
```
离线浮雕也支持：`--mode relief`。

## 六、Docker（仅离线模式）

```bash
docker compose up --build
```
> 容器内默认不含 GPU 与 AI 权重，AI 模式需自行在带 GPU 的主机按上面步骤部署。
