# 部署与接入 AI 模式

## 一、最小可用（离线浮雕模式）

不需要显卡、不需要任何模型权重。按 README 的「快速开始」启动即可。
该模式把照片亮度转成带颜色的浮雕刻印，满足「开箱即跑」。

## 二、权重下载（开箱即用 / 离线预置）⭐

SnapPrint 的 AI 后端把权重放到 `models/<目录>`，与 `app/config.py` 的模型
动物园一一对应。下面给出各后端的 **HuggingFace 仓库链接** 与 **一行下载命令**，
下载后即为「开箱即用」（无需运行时再联网拉取）。

> 前置：**NVIDIA GPU + CUDA**（CPU 基本跑不动 AI 模式）。
> 国内用户请在命令前加 `export HF_ENDPOINT=https://hf-mirror.com`（见第五节）。

| 后端 | 权重目录 (`models/`) | HuggingFace 仓库 | 一键下载命令 |
|---|---|---|---|
| Hunyuan3D-2（通用） | `Hunyuan3D-2` | [tencent/Hunyuan3D-2](https://huggingface.co/tencent/Hunyuan3D-2) | `huggingface-cli download --resume-download tencent/Hunyuan3D-2 --local-dir models/Hunyuan3D-2` |
| Hunyuan3D-2 Mini（轻量） | `Hunyuan3D-2mini` | [tencent/Hunyuan3D-2mini](https://huggingface.co/tencent/Hunyuan3D-2mini) | `huggingface-cli download --resume-download tencent/Hunyuan3D-2mini --local-dir models/Hunyuan3D-2mini` |
| Hunyuan3D-2 Mini Turbo | `Hunyuan3D-2-mini-turbo` | [tencent/Hunyuan3D-2-mini-turbo](https://huggingface.co/tencent/Hunyuan3D-2-mini-turbo) | `huggingface-cli download --resume-download tencent/Hunyuan3D-2-mini-turbo --local-dir models/Hunyuan3D-2-mini-turbo` |
| Hunyuan3D-2 Mini Fast | `Hunyuan3D-2-mini-fast` | [tencent/Hunyuan3D-2-mini-fast](https://huggingface.co/tencent/Hunyuan3D-2-mini-fast) | `huggingface-cli download --resume-download tencent/Hunyuan3D-2-mini-fast --local-dir models/Hunyuan3D-2-mini-fast` |
| TripoSR（轻量快速） | `TripoSR` | [stabilityai/TripoSR](https://huggingface.co/stabilityai/TripoSR) | 克隆仓库（见第三节）；权重运行时自动拉取，或预置 `huggingface-cli download --resume-download stabilityai/TripoSR --local-dir models/TripoSR` |
| TripoSG（几何质量高） | `TripoSG` | [VAST-AI/TripoSG](https://huggingface.co/VAST-AI/TripoSG) | `huggingface-cli download --resume-download VAST-AI/TripoSG --local-dir models/TripoSG`（另需 RMBG-1.4 与 DINOv3，见注） |
| SF3D（秒级·拓扑干净） | `SF3D` | [stabilityai/stable-fast-3d](https://huggingface.co/stabilityai/stable-fast-3d) | 需先 `huggingface-cli login` 同意协议，再 `huggingface-cli download --resume-download stabilityai/stable-fast-3d --local-dir models/SF3D` |
| Trellis2（高质量） | `Trellis2` | [microsoft/TRELLIS-image-large](https://huggingface.co/microsoft/TRELLIS-image-large) | `huggingface-cli download --resume-download microsoft/TRELLIS-image-large --local-dir models/Trellis2` |

> 注：模型动物园里的 `figure / jewelry / ecom` 垂类默认 `available=False`，
> 需要你自备对应社区微调权重放到 `models/Hunyuan3D-2-<垂类>` 目录。

**脚本一键版**（推荐，自动处理目录映射与镜像）：

```bash
# 安装 hy3dgen 依赖 + 预置 Hunyuan3D-2 权重（国内加 --mirror hf）
python scripts/setup_ai_models.py --hunyuan3d --download tencent/Hunyuan3D-2
# 仅下载某个权重
python scripts/setup_ai_models.py --hunyuan3d-mini --mirror hf
python scripts/setup_ai_models.py --triposg
python scripts/setup_ai_models.py --sf3d          # 需先 huggingface-cli login
python scripts/setup_ai_models.py --trellis
# 全部（耗时较长）
python scripts/setup_ai_models.py --all --mirror hf
# 检查本机各后端可用性
python scripts/setup_ai_models.py --check
```

## 三、接入 Hunyuan3D-2（质量最高的图生 3D）

> 前置：**NVIDIA GPU + CUDA**。CPU 基本跑不动。

1. 安装带 CUDA 的 PyTorch（按你的驱动版本选 cu 链接）：
   ```bash
   pip install torch --index-url https://download.pytorch.org/whl/cu121
   ```
2. 安装 Hunyuan3D 推理包：
   ```bash
   pip install hy3dgen
   ```
3. （可选，离线/预置）把权重下载到 `models/Hunyuan3D-2`：
   ```bash
   huggingface-cli download --resume-download tencent/Hunyuan3D-2 --local-dir models/Hunyuan3D-2
   ```
4. 在 Web UI 选择「AI 模式（Hunyuan3D）」或调用：
   ```python
   from app.pipeline import run
   run(image_bytes, mode="hunyuan3d", out_dir="outputs/demo")
   ```
5. 权重默认自动从 HuggingFace (`tencent/Hunyuan3D-2`) 拉取；
   若已预置到 `models/Hunyuan3D-2`，程序会优先用本地权重（断网也能跑）。

## 四、接入 TripoSR（轻量快速）

> 前置：**NVIDIA GPU + CUDA**。

1. 把 TripoSR 仓库克隆到 `models/`，并安装其依赖：
   ```bash
   git clone https://github.com/stabilityai/TripoSR models/TripoSR
   pip install -r models/TripoSR/requirements.txt
   ```
   （或用脚本：`python scripts/setup_ai_models.py --triposr`）
2. （可选，离线/预置）把权重预置到 `models/TripoSR`：
   ```bash
   huggingface-cli download --resume-download stabilityai/TripoSR --local-dir models/TripoSR
   ```
3. 在 Web UI 选择「AI 模式（TripoSR）」或调用：
   ```python
   from app.pipeline import run
   run(image_bytes, mode="triposr", out_dir="outputs/demo")
   ```
4. 权重默认自动拉取 `stabilityai/TripoSR`；也可离线放置到 `models/TripoSR`。

## 五、国内加速镜像

HuggingFace 直连不稳时，二选一：

**方案 A — hf-mirror.com（最省事，推荐）**
```bash
export HF_ENDPOINT=https://hf-mirror.com
# 然后照常执行上面的 huggingface-cli download 命令即可
```

**方案 B — ModelScope（仅 Hunyuan3D 系列有官方镜像）**
```bash
pip install modelscope
python - <<'PY'
from modelscope import snapshot_download
# 仓库 ID 用 AI-ModelScope/ 前缀
snapshot_download('AI-ModelScope/Hunyuan3D-2', cache_dir='models/Hunyuan3D-2')
snapshot_download('AI-ModelScope/Hunyuan3D-2mini', cache_dir='models/Hunyuan3D-2mini')
PY
```
或直接用脚本的 `--mirror modelscope`：
```bash
python scripts/setup_ai_models.py --hunyuan3d-mini --mirror modelscope
```

## 六、统一接口契约（想接别的模型就看这里）

任意后端只需实现：
```python
def image_to_mesh(self, image: PIL.Image) -> trimesh.Trimesh:
    ...
```
SnapPrint 的 `backends.HunyuanBackend` / `TripoSRBackend` 已按此契约
对接真实开源库，并通过 `_to_trimesh()` 把不同返回类型统一成 trimesh。
要加新后端：在 `app/backends.py` 继承 `Backend`，并在 `get_backend()` 注册即可。

## 七、命令行批量生成（适合 GPU 服务器）

```bash
python scripts/generate_cli.py photo.jpg --mode hunyuan3d --out outputs/cli --device cuda --steps 50
```
离线浮雕也支持：`--mode relief`。

## 八、Docker（仅离线模式）

```bash
docker compose up --build
```
> 容器内默认不含 GPU 与 AI 权重，AI 模式需自行在带 GPU 的主机按上面步骤部署。
