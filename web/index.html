🧩 模型实例库

16 款内置参数化真 3D 几何（花瓶、宝石、圆环、棋子、灯笼…），无需照片、全部水密可直接打印。点选一款，可调尺寸后一键生成并发布到社区。

⚠️ 社区后端未连接：画廊 / 上传 / 评论需要 Python 后端。 在本地运行 python -m app.main 后访问 http://localhost:8000；或部署后端到 Python 主机后， 在 web/config.js 把 API_BASE 改成后端地址。
